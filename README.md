# MovieApi

ASP.NET Core Web API ve React kullanılarak geliştirilmiş basit bir film listeleme uygulaması.

## Özellikler

- Tüm filmleri listeleme
- Id'ye göre film detayı getirme

## Kullanılan Teknolojiler

**Backend**
- ASP.NET Core Web API
- Entity Framework Core, SQL Server
   
**Frontend**
- React 
- Typescript
- TailwindCSS
- MaterialUI
